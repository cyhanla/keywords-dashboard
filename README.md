## 🚀 部署到 GitHub Pages

### 步骤1：创建GitHub仓库
1. 登录 GitHub
2. 点击右上角 **+** → **New repository**
3. 仓库名填：`mingranju-dashboard`（或其他名字）
4. 选择 **Public**（Public才能免费使用GitHub Pages）
5. 点击 **Create repository**

### 步骤2：上传文件
在仓库页面，点击 **uploading an existing file**，把下面这4个文件传上去：
- `index.html`
- `top20.html`
- `fufei.html`
- `complete.html`

### 步骤3：开启GitHub Pages
1. 进入仓库的 **Settings** → 左侧 **Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选择 **main** → **/(root)**
4. 点击 **Save**

等待1-2分钟，访问 `https://你的用户名.github.io/mingranju-dashboard` 即可看到网站。

## 📝 更新数据

需要更新时，直接修改HTML文件里的数据部分，重新上传到GitHub即可。
